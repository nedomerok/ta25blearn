# ta25blearn

## Running

```bash
npm install
npm run dev
```
Open the address shown by Vite in the terminal (usually http://localhost:5173).
## Features
-Add new items to the shopping list;
-Choose a high, medium, or low importance level for each item;
-Sort items by importance, from highest to lowest;
-Mark items as completed;
-Display all items, completed items, and unfinished items in separate sections;
-Use different colors to show item importance:
  Red for high importance.
  Yellow for medium importance.
  Green for low importance.
-Style each item using the Bulma box component.
