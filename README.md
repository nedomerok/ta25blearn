# Мой список задач

Учебный проект на Vue 3, Vite и Bulma.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который Vite покажет в терминале (обычно http://localhost:5173).

## Что умеет приложение

- добавлять задачи;
- выбирать высокий, средний или низкий приоритет;
- сортировать задачи по приоритету;
- отмечать задачи выполненными;
- отображать активные и выполненные задачи отдельно;
- оформлять каждую задачу компонентом Bulma `box`.
